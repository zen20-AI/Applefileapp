Install

วิธีติดตั้ง

  1. Open Petal.dmg and drag Petal into Applications.
  2. If macOS says it can't be opened: System Settings → Privacy & Security → Open Anyway (once — Petal isn't notarized yet; updates install by themselves).
  3. Allow folder access in the welcome window. Petal lives in the menu bar — look for the petal icon.
  1. เปิด Petal.dmg แล้วลาก Petal ไปไว้ใน Applications
  2. ถ้า macOS แจ้งว่าเปิดไม่ได้: ไปที่ System Settings → Privacy & Security → Open Anyway (ทำครั้งเดียว อัปเดตครั้งต่อไปติดตั้งเอง)
  3. กดอนุญาตการเข้าถึงโฟลเดอร์ในหน้าต้อนรับ Petal อยู่ที่แถบเมนูด้านบน (ไอคอนกลีบดอก)
