## ติดตั้งใน 3 ขั้นตอน

**1. ดาวน์โหลด** [**Petal.dmg**](https://github.com/AImunich20/petal-releases/releases/latest/download/Petal.dmg) แล้วดับเบิลคลิกเพื่อเปิด

**2. ลาก Petal ไปวางในโฟลเดอร์ Applications**

<p align="center"><img src="images/install.png" width="460" alt="ลาก Petal ไปที่ Applications"></p>

**3. เปิด Petal จาก Applications หรือ Launchpad**

ถ้าขึ้นว่า *"Petal" can't be opened* หรือ *Apple could not verify…* (เกิดเฉพาะครั้งแรก เพราะ Petal ยังไม่ได้ลงทะเบียนกับ Apple):

1. กด **Done** หรือ **OK** เพื่อปิดหน้าต่างเตือน
2. เปิด **System Settings → Privacy & Security**
3. เลื่อนลงไปจะเห็น *"Petal" was blocked…* ให้กด **Open Anyway** แล้วใส่รหัสผ่านเครื่อง
4. กด **Open** อีกครั้ง

ทำแค่ครั้งเดียว การอัปเดตครั้งต่อไปจะติดตั้งให้เอง

> **หาไม่เจอหลังเปิดแอป?** Petal ไม่มีหน้าต่างหลักและไม่มีไอคอนใน Dock มันอยู่ที่ **แถบเมนูด้านบนขวาของจอ** (ไอคอนรูปกลีบดอก ✿)
> ครั้งแรกจะมีหน้าต้อนรับให้กด **Allow All** เพื่ออนุญาตให้ Petal เข้าถึง Desktop, Documents, Downloads และ Pictures

## ใช้งานอย่างไร

### 1. ลากไฟล์ใดก็ได้ แล้ววงแหวนจะบานขึ้นข้างเมาส์

เริ่มลากรูป PDF หรือเอกสารจาก Finder หรือ Desktop แล้ววงแหวนเครื่องมือจะเปิดขึ้นข้างเมาส์ วางไฟล์บนกลีบที่ต้องการได้เลย
ไฟล์ใหม่จะบันทึกไว้ข้างไฟล์เดิม เช่น `รูป Compressed.jpg` ส่วน **ต้นฉบับไม่ถูกแก้ไข**

- วงแหวนแสดงเฉพาะเครื่องมือที่ใช้กับไฟล์นั้นได้
- ลากไฟล์ค้างไว้ที่วงกลมตรงกลางครึ่งวินาที เพื่อสลับระหว่าง **เครื่องมือ** กับ **แปลงไฟล์** (PNG, JPG, HEIC, PDF, DOCX…)
- เลือกไฟล์ใน Finder แล้วกด **⌥⌘P** ก็เปิดวงแหวนได้เหมือนกัน

### 2. แผงควบคุมบนแถบเมนู

<img src="images/panel.png" width="400" align="right" alt="แผงควบคุมบนแถบเมนู">

คลิกไอคอน ✿ บนแถบเมนูเพื่อเปิดแผงนี้

- **Drag Ring:** เปิดหรือปิดวงแหวนตอนลากไฟล์
- **Drop files here:** วางไฟล์ตรงนี้ หรือคลิกเพื่อเลือกไฟล์
- **Shelf · Workspace · Automation · History · Settings:** ทางลัดไปส่วนต่าง ๆ
- **⤓:** ตรวจหาอัปเดต
- **⏻:** ออกจาก Petal

<br clear="right">

### 3. บีบอัดให้ไม่เกินขนาดที่ต้องการ

เว็บสมัครงาน เว็บราชการ หรืออีเมลที่จำกัดขนาดไฟล์ไว้ 1 MB หรือ 2 MB ก็ใช้ได้ Petal จะหาคุณภาพที่ดีที่สุดที่ยังไม่เกินขนาดให้เอง

<p align="center"><img src="images/compress.png" width="560" alt="บีบอัดรูป 11.3 MB ให้ไม่เกิน 1 MB"></p>

ตั้งค่าที่ **Settings → บีบอัดเป็น → ไม่เกิน 500 KB / 1 MB / 2 MB / 5 MB…** แล้วกลีบ Compress บนวงแหวนจะเปลี่ยนเป็น **≤ 1 MB**
หรือคลิกขวาไฟล์ใน Finder → **Services → Petal: Compress to Under 1 MB**

### 4. Shelf: ที่พักไฟล์

<img src="images/shelf.png" width="400" align="right" alt="Shelf">

แผงเล็ก ๆ ที่ลอยอยู่ขอบจอ ใช้พักไฟล์ไว้ก่อน แล้วค่อยลากไปใช้ทีหลัง

- **เอาไฟล์เข้า:** ลากไฟล์มาวาง หรือวางบนกลีบ **Shelf** ของวงแหวน
- **ผลลัพธ์จาก Petal มารอที่นี่เอง** พร้อมลากไปแนบ LINE หรืออีเมล
- **ลากออกทีละไฟล์** หรือลาก **ไอคอนกองไฟล์มุมซ้ายบน** เพื่อหยิบทุกไฟล์พร้อมกัน
- **ปุ่มคัดลอก:** กดแล้วไปวาง (⌘V) ใน LINE, Mail หรือ Finder ได้เลย

## คำถามที่พบบ่อย

<details>
<summary><b>ทำไม macOS เตือนว่าเปิดไม่ได้ ปลอดภัยไหม?</b></summary>

Petal ยังไม่ได้ลงทะเบียน Developer ID กับ Apple (มีค่าใช้จ่ายรายปี) macOS จึงเตือนแอปที่ดาวน์โหลดจากเว็บทุกตัวที่ยังไม่ได้ลงทะเบียน
ให้กด **Open Anyway** ตามขั้นตอนที่ 3 ด้านบน Petal ไม่ส่งไฟล์หรือข้อมูลใด ๆ ออกจากเครื่อง การเชื่อมต่อเดียวที่มีคือการเช็กอัปเดตจากหน้านี้
</details>

<details>
<summary><b>อัปเดตอย่างไร?</b></summary>

Petal เช็กอัปเดตให้เอง และจะแจ้งเมื่อมีเวอร์ชันใหม่ ถ้าอยากเช็กเองตอนนี้ ให้คลิก ✿ บนแถบเมนู แล้วกดปุ่ม **⤓**
</details>

<details>
<summary><b>ลากไฟล์แล้ววงแหวนไม่ขึ้น</b></summary>

- ดูว่า **Drag Ring** ในแผงควบคุมเปิดอยู่ (สีเขียว)
- ต้องลากไฟล์ออกไปไกลกว่าระยะที่ตั้งไว้เล็กน้อย ปรับได้ที่ Settings → Drag Ring
- ถ้ายังไม่ขึ้น ใช้ **⌥⌘P** กับไฟล์ที่เลือกใน Finder หรือวางไฟล์ในแผงควบคุมแทนได้
</details>

<details>
<summary><b>เมนู Petal ไม่ขึ้นตอนคลิกขวาใน Finder</b></summary>

ไปที่ **System Settings → Keyboard → Keyboard Shortcuts → Services → Files and Folders** แล้วติ๊กรายการที่ขึ้นต้นด้วย *Petal:*
</details>

<details>

Petal ใช้ภาษาตามเครื่องโดยอัตโนมัติ ถ้าต้องการเปลี่ยน ไปที่ Settings → Language แล้วกด Restart

<details>
<summary><b>ถอนการติดตั้ง</b></summary>

</details>

## English

**Petal** is a free macOS menu bar app. Start dragging any file and a ring of tools blooms beside the pointer. Drop the file on a petal to work with it, all on your Mac:
- convert it
- compress it, to a size limit if you like
- copy its text (OCR)
- cut out the background
- merge, split or sign PDFs
- park it on the Shelf

Results are saved as new files next to the original. Originals are never changed.

**[⬇ Download Petal.dmg](https://github.com/AImunich20/petal-releases/releases/latest/download/Petal.dmg)** — macOS 14 or later, Apple silicon and Intel.

1. Open the DMG and drag **Petal** into **Applications**.
2. Open Petal. If macOS says it can't be opened, close the alert, then go to **System Settings → Privacy & Security → Open Anyway**. You only need to do this once; updates install by themselves.
3. Look for the ✿ icon in the menu bar. Click **Allow All** in the welcome window so Petal can save next to your files.

Tips:
- **⌥⌘P** opens the ring for the files selected in Finder.
- **Settings → Compress to** sets a size limit, such as 1 MB.
- The **Shelf** keeps files at the edge of the screen until you drag them out.
